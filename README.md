# Avery의 서울

Avery를 위한 서울 여행 가이드. 빌드 없는 정적 사이트(HTML/CSS/JS)예요.

## 열어보기
`index.html`을 더블클릭하면 브라우저에서 열려요.
휴대폰 크기로 보려면 크롬 개발자도구(F12) → 기기 툴바(Ctrl+Shift+M)에서 390px로 맞추면 돼요.

## 장소 추가·수정 — 관리자 페이지 (코드 안 열어도 됨)
사이트 주소 뒤에 `/admin.html`을 붙여 열면 동네별로 장소를 추가·수정·삭제·순서 변경할 수 있어요.
저장하면 GitHub에 바로 커밋되고, 1~2분 뒤 사이트에 반영돼요.
이미 사이트를 열어둔 사람도 1분 안에(또는 앱으로 다시 돌아올 때) 자동으로 새로고침돼서 바뀐 내용이 보여요 (`app.js` 맨 아래 "자동 새로고침"). 사진도 거기서 고르면 알아서 줄여서 `images/places/`에 올려줘요.
- 처음 한 번만 GitHub 토큰이 필요해요 (만드는 법은 페이지에 나와요). 토큰은 그 브라우저에만 저장돼요.
- 쇼핑은 "구경"으로 넣어요.
- **Simple Korean 녹음**: 맨 위 "🎙 Simple Korean 녹음" 탭에서 문장마다 직접 녹음(또는 음성 메모 파일 올리기)할 수 있어요.
  녹음은 `audio/phrases/`에 WAV로, 연결 목록은 `voices.js`에 저장돼요. 녹음이 없는 문장은 휴대폰 목소리가 읽어줘요.
  `data.js`에서 문장 한글을 고치면 그 문장은 다시 녹음해야 해요.

## 앨범 (하단 탭 📷)
한국에서 찍은 사진을 3열 그리드로 모아 보는 화면이에요. 사진을 누르면 크게 보이고(사진을 한 번 더 누르면 2배 확대, 좌우로 밀면 다음 사진), 저장 버튼으로 내려받아요.
- **올리기**: "사진 올리기" → 사진 여러 장 고르기 → 날짜·장소 확인 → 올리기. 바로 모두의 앨범에 보여요. 키·로그인 없이 사이트를 아는 사람은 누구나 올릴 수 있어요.
  - 날짜는 사진 속 정보(EXIF)에서, 장소는 GPS가 있으면 자동으로 채워요 (추천 장소 150m 안이면 그 이름, 아니면 OpenStreetMap 주소). 직접 고칠 수도 있어요.
  - 아이폰은 사진을 고를 때 아래 "옵션"에서 **위치**를 켜야 GPS가 같이 넘어와요. 꺼져 있으면 장소는 직접 적어주세요.
- **저장**: 아이폰은 공유 시트의 "이미지 저장"으로 사진 앱에 바로 들어가요. 안드로이드·컴퓨터는 파일로 내려받아요(갤러리의 Download 폴더).
- **저장소: Supabase (무료 플랜)** — 사진 파일은 Storage `album` 버킷(`photos/` 긴 변 2048px, `thumbs/` 그리드용), 날짜·장소는 `photos` 테이블. 1GB면 약 1,500장.
  - 처음 설정: ① [supabase.com](https://supabase.com)에서 새 프로젝트 만들기 ② SQL Editor에 `supabase-setup.sql` 내용을 붙여넣고 Run ③ Project Settings → API Keys의 프로젝트 주소와 공개(publishable) 키를 `album-store.js` 맨 위 두 칸에 넣기.
  - 사진을 빼거나 장소를 고치려면 Supabase 대시보드 → Table Editor → `photos`에서 그 줄을 고치거나 지우세요. (파일까지 지우려면 Storage → `album`에서도)
  - ⚠️ 무료 프로젝트는 **일주일 동안 아무도 안 쓰면 일시정지**돼요. 사진은 그대로 있고, 대시보드에서 "Restore"를 누르면 다시 열려요.

## 내용 고치기 — 코드로 직접
- **장소**: `places.js` (관리자 페이지가 고치는 파일). 한 줄에 장소 하나(JSON)예요.
  ```js
  {"area":"namdaemun","kind":"eat","ll":[37.5,126.9],"name":{"ko":"가게 이름","en":""},"note":{"ko":"한 줄 추천","en":""},"naverUrl":"https://naver.me/..."},
  ```
  - `kind`: `eat`(먹기) / `see`(구경·쇼핑) / `walk`(걷기)
  - 지도 링크를 비워두면 "한글 이름 + 지역 검색어"로 검색 링크가 자동으로 만들어져요.
    검색이 엉뚱하게 나오면 `"query": "토속촌 삼계탕 서촌"`처럼 검색어를 직접 넣어주세요.
  - 사진: `"photo": "images/places/파일이름.jpg"` → 카드 왼쪽에 정사각형으로 보여요. 비워두면 이모지가 대신 보여요.
  - **지도 핀**: `"ll": [위도, 경도]`를 넣으면 지역 화면의 "추천 장소 지도"에 핀이 꽂혀요. 없으면 핀만 빠져요.
    구글 지도에서 장소를 꾹 누르면 위에 `37.57975, 126.97668` 같은 숫자가 나오니 그대로 복사하세요.
    (지도: MapLibre + OpenFreeMap — API 키 없음. 색은 `app.js`의 `MAP_COLORS`에서 바꿔요)
- **그 밖의 내용**(지역 소개, 팁, 호텔 등): `data.js`
- **지역 대표 사진**: `images/areas/{지역id}.jpg` (지금은 Wikimedia Commons 사진). 바꾸려면 같은 이름으로 덮어쓰거나 `data.js`의 `image` 경로를 수정하세요. 파일이 없으면 이모지가 대신 보여요.
- **영어**: 각 `en` 칸을 채우면 우측 상단 `한/EN` 버튼으로 바꿔 볼 수 있어요. 비어 있으면 한글이 보여요.
